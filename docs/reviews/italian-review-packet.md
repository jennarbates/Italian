## How the game talks

- Every question is yes/no and uses one of three patterns:
  - `Ha {article} {noun}?`, for example *Ha la barba?*
  - `Ha {article} {noun} {adjective}?`, for example *Ha gli occhi verdi?*
  - `È {article} {noun}?`, for example *È una donna?*
- The answer repeats the question as a sentence:
  - Yes: `Sì, ` + the question with a lowercase first letter + `.`
  - No: `No, non ` + the question with a lowercase first letter + `.`
- The answer always uses the word the player chose. If the player asked with *castani*, the answer says *castani*.
